# AREHAJ Planned Actions and Reactions Phase 1

This document describes the actions and reactions that we are considering for AREHAJ as of phase 1.

## Requirements

There are four members in our group.  
`(Actions + Reactions) >= 2 × M + 2 = 10`  
We must implement at least 10 actions and reactions.

## Plan

Actions:

- On receiving an gmail email
- On Github push
- On addition of a new row in Google Sheets
- On creation of a new file in Google Drive
- On creation of a new document in Google Docs
- On receiving a message in WhatsApp
- On creation of a new company post in Linkedin
- On addition of a new event in Google Calendar
- On completion of a Google forms
- On publication of a new video from a Youtube channel

Reactions:

- Sending an email
- Add row in Google Sheets
- Create file in Google Drive
- Send WhatsApp Message
- Create Linkedin Post
- Create Google Calendar Event
- Send Discord Message
- Download file from Google Drive
- Upload File in Google Drive
- Create Folder in Google Drive
- Update Google Sheet row
- Delete Google Sheet row
- Create new Trello

For a total of 10 Actions and 13 Reactions.
